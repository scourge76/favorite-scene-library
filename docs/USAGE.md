# Usage / Bedienung

## English

### Create a Kodi bookmark

1. Play a movie and pause at the beginning of the scene.
2. Open the on-screen playback controls.
3. Open **Bookmarks**.
4. Choose **Create bookmark** or **New bookmark**.
5. Open FSL or run **Synchronize Kodi Bookmarks**.

### Add FSL to the Kodi home screen

1. Open the settings of your Kodi skin.
2. Open the home-menu customization.
3. Add a new main-menu item named **FSL**.
4. Set its action to **Add-ons → Video add-ons → Favorite Scene Library**.
5. Add a widget and select **Favorite Scene Library → Movies** as its source.

Using **Movies** is recommended because the widget shows one poster per movie. Selecting a poster opens only the saved scenes for that movie.

## Deutsch

### Kodi-Lesezeichen erstellen

1. Einen Film starten und am Beginn der gewünschten Szene pausieren.
2. Die Wiedergabesteuerung einblenden.
3. **Lesezeichen** öffnen.
4. **Lesezeichen erstellen** oder **Neues Lesezeichen** auswählen.
5. FSL öffnen oder **Kodi-Lesezeichen synchronisieren** ausführen.

### FSL auf der Kodi-Startseite einrichten

1. Die Einstellungen des verwendeten Kodi-Skins öffnen.
2. Die Anpassung des Startmenüs öffnen.
3. Einen neuen Hauptmenüpunkt mit dem Namen **FSL** anlegen.
4. Als Aktion **Add-ons → Video-Add-ons → Favorite Scene Library** auswählen.
5. Ein Widget hinzufügen und als Quelle **Favorite Scene Library → Filme** auswählen.

**Filme** wird empfohlen, weil dadurch pro Film nur ein Poster erscheint. Nach Auswahl des Posters werden ausschließlich die gespeicherten Szenen dieses Films angezeigt.
