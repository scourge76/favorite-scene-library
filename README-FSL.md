# Favorite Scene Library (FSL)

**A Kodi add-on for organizing and instantly playing favorite movie scenes.**  
**Ein Kodi-Add-on zum Organisieren und direkten Abspielen deiner Lieblingsfilmszenen.**

Developed by **Scourge**

---

## English

Favorite Scene Library turns Kodi video bookmarks into a clear, browsable scene collection. FSL reads the bookmarks already stored in Kodi and lets you rename scenes, assign categories and start playback at the exact saved position.

### Features

- Imports existing Kodi video bookmarks
- Starts playback at the exact saved timestamp
- Browse scenes by movie or category
- Rename scenes
- Assign categories
- Uses posters, fanart and available scene thumbnails
- Separate SQLite database for FSL metadata
- German and English interface
- Suitable for a dedicated Kodi home-menu entry and home-screen widgets

### Installation

1. Download `plugin.video.favoritescenelibrary-1.0.0.zip` from the Releases section.
2. Open Kodi.
3. Go to **Add-ons → Install from zip file**.
4. Select the downloaded ZIP file.
5. Open **Favorite Scene Library** from the video add-ons.

### Creating a bookmark in Kodi

1. Start the movie and pause at the beginning of the scene you want to save.
2. Open Kodi's on-screen playback controls.
3. Open **Bookmarks**. Depending on the skin, this appears as a bookmark/page icon or under the additional playback options.
4. Select **Create bookmark** or **New bookmark**.
5. Kodi stores the current playback position. FSL imports it the next time you open or synchronize the add-on.

A normal scene bookmark is required. A resume point alone does not create an FSL scene.

### How FSL works

1. Create one or more bookmarks while watching a movie.
2. Open FSL or select **Synchronize Kodi Bookmarks**.
3. Open **Movies** and select the corresponding movie poster.
4. Open the context menu on a scene to rename it or assign a category.
5. Select the scene to start the movie at the saved position.

Removing an entry from FSL does not delete the original Kodi bookmark.

### Dedicated home-menu entry and widget

FSL can be added as its own main-menu item in skins that support custom menu entries, such as Arctic Fuse or Arctic Zephyr.

Recommended setup:

1. Open the skin settings.
2. Go to **Home menu customization**.
3. Add a new main-menu item and name it **FSL**.
4. Set its action to open **Add-ons → Video add-ons → Favorite Scene Library**.
5. Add a widget to this menu item.
6. For the widget source choose **Favorite Scene Library → Movies**.

The **Movies** widget is recommended instead of **All Scenes**. It displays one poster per movie and remains clear even with many saved scenes. Selecting a poster opens only the scenes saved for that movie.

Additional widgets can also be created from **Categories**, for example Atmos, Bass Demo, Dolby Vision or Favorites.

## Deutsch

Favorite Scene Library macht aus den in Kodi gespeicherten Video-Lesezeichen eine übersichtliche Szenenbibliothek. FSL übernimmt vorhandene Lesezeichen, ermöglicht das Umbenennen und Kategorisieren und startet den Film exakt an der gespeicherten Position.

### Funktionen

- Übernimmt vorhandene Kodi-Video-Lesezeichen
- Startet Filme exakt an der gespeicherten Position
- Szenen nach Film oder Kategorie anzeigen
- Szenen umbenennen
- Kategorien vergeben
- Verwendet Poster, Fanart und vorhandene Szenenbilder
- Eigene SQLite-Datenbank für FSL-Zusatzinformationen
- Deutsche und englische Benutzeroberfläche
- Als eigener Kodi-Menüpunkt und als Startseiten-Widget nutzbar

### Installation

1. `plugin.video.favoritescenelibrary-1.0.0.zip` im Bereich **Releases** herunterladen.
2. Kodi öffnen.
3. **Add-ons → Aus ZIP-Datei installieren** auswählen.
4. Die heruntergeladene ZIP-Datei auswählen.
5. **Favorite Scene Library** unter den Video-Add-ons öffnen.

### Ein Lesezeichen in Kodi erstellen

1. Den Film starten und am Anfang der gewünschten Szene pausieren.
2. Die Wiedergabesteuerung von Kodi einblenden.
3. **Lesezeichen** öffnen. Je nach Skin befindet sich die Funktion hinter einem Lesezeichen-/Seiten-Symbol oder in den weiteren Wiedergabeoptionen.
4. **Lesezeichen erstellen** oder **Neues Lesezeichen** auswählen.
5. Kodi speichert die aktuelle Filmposition. FSL übernimmt das Lesezeichen beim nächsten Öffnen oder nach **Kodi-Lesezeichen synchronisieren**.

Wichtig: Ein normal angelegtes Szenen-Lesezeichen ist erforderlich. Ein bloßer Fortsetzungspunkt reicht nicht aus.

### So funktioniert FSL

1. Während der Filmwiedergabe ein oder mehrere Kodi-Lesezeichen anlegen.
2. FSL öffnen oder **Kodi-Lesezeichen synchronisieren** auswählen.
3. Unter **Filme** das Poster des entsprechenden Films öffnen.
4. Über das Kontextmenü die Szene umbenennen oder einer Kategorie zuordnen.
5. Die Szene auswählen. Der Film startet direkt an der gespeicherten Position.

Wird ein Eintrag aus FSL entfernt, bleibt das ursprüngliche Kodi-Lesezeichen erhalten.

### Eigener Menüpunkt und Startseiten-Widget

FSL kann in Skins mit frei konfigurierbarem Hauptmenü, beispielsweise Arctic Fuse oder Arctic Zephyr, als eigener Menüpunkt angelegt werden.

Empfohlene Einrichtung:

1. Die Einstellungen des verwendeten Skins öffnen.
2. **Startmenü anpassen** beziehungsweise **Home menu customization** öffnen.
3. Einen neuen Hauptmenüpunkt anlegen und ihn **FSL** nennen.
4. Als Aktion **Add-ons → Video-Add-ons → Favorite Scene Library** auswählen.
5. Für diesen Menüpunkt ein Widget hinzufügen.
6. Als Widget-Quelle **Favorite Scene Library → Filme** auswählen.

Das Widget **Filme** ist übersichtlicher als **Alle Szenen**. Auf der Startseite erscheint dadurch pro Film nur ein Poster. Nach Auswahl eines Posters werden ausschließlich die für diesen Film gespeicherten Szenen angezeigt.

Zusätzlich können Widgets aus **Kategorien** angelegt werden, beispielsweise Atmos, Bass Demo, Dolby Vision oder Favoriten.
